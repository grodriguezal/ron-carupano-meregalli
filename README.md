# Ron Carúpano · Meregalli Italia

Dashboard comercial basado en los dos archivos de ventas e incentivos compartidos. Aplicación web estática en `index.html`; los datos se sirven desde `data.json`.

Publicación prevista en GitHub Pages: https://grodriguezal.github.io/ron-carupano-meregalli/

**Cautela:** el período de las ventas 2025/2026 no está confirmado; el archivo de incentivos declara 01/09–31/10/2026. No sumar ni equiparar ambas fuentes.
